# IRD Assistant v2.7.9.11 — Build & Validation Report

## Exact production-visible error
Reproduced in Chromium: `TypeError: Cannot read properties of null (reading 'addEventListener')` at the notification footer handler in `assistant.js`.

## Root cause
The Vercel `index.html` notification modal uses the header `closeNotifications` button only and has no `closeNotificationsFooter` node. The shared `assistant.js` assumed that node always existed. That assumption is true for the extension `assistant.html` but false for the Vercel page. The exception occurred while binding handlers and triggered the app-level runtime error banner.

## Minimal fix
In both `assistant.js` copies, the footer close handler is registered conditionally:

```js
const notificationFooterClose = $('closeNotificationsFooter');
if (notificationFooterClose) notificationFooterClose.addEventListener('click', closeNotifications);
```

This preserves the extension footer button and allows Vercel to use its existing modal close icon without adding/removing UI.
