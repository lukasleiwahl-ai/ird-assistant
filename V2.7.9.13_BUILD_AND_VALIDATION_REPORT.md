# IRD Assistant Vercel v2.7.9.13 — Build & Validation Report

## Scope
Vercel-only in-app popup banners for Task Completed and Task Reply. Shared Apps Script backend emits reply events into the existing `IRD NOTIFICATIONS` sheet. The Vercel runtime bridge from v2.7.9.12 is retained.

## Changes
- `index.html`: Vercel bridge loaded before assistant script; live toast container added; asset cache versions advanced.
- `assistant.css`: additive live toast styles.
- `assistant.js`: detects newly-arrived notification IDs, shows popup banner, queues latest event, opens task/discussion when clicked; notification polling is 5 seconds while app is open.
- `google-apps-script/Code.gs`: creates a de-duplicated `TASK_REPLY` notification after persisting each reply; suppresses a user's own reply from that user's feed.
- `service-worker.js`, `manifest.json`, `package.json`: version metadata advanced.

## Validation performed
- JavaScript syntax checks: `assistant.js`, `vercel-bridge.js`, Apps Script `Code.gs`, `options.js`, `popup.js`, `service-worker.js`, `api/push.js`.
- JSON parse checks: `manifest.json`, `package.json`, `google-apps-script/appsscript.json`.
- ZIP integrity check.
- Source scope check: no `browser-extension/` files are included in this Vercel-only package.

## Production checks still required
- Deploy updated `google-apps-script/Code.gs` as a new Web App version in the existing Apps Script deployment, preserving its `/exec` URL and permissions.
- Deploy all files in this package to the existing Vercel project root.
- Confirm Vercel Settings still uses the same Apps Script URL and Spreadsheet ID as the shared IRD Assistant backend.
- Test task completion from one device and reply from a second device; verify popup, click-through, unread badge, and no self-notification for the reply sender.
- Live production Sheets writes and multi-device behavior have not been verified from this build environment.
