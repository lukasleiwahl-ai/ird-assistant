## Deployment order
1. Replace the active Apps Script `Code.gs` with `google-apps-script/Code.gs` and deploy a **New version** of the existing Web App. Keep the current Web App URL, spreadsheet ID and sheet names. Check timezone `Asia/Jakarta`.
2. Deploy the full project root to the existing Vercel project. Do not set Vercel Root Directory to `browser-extension/`.
3. Install/update the browser extension by loading the extracted `browser-extension/` folder in `chrome://extensions` or `edge://extensions` with Developer Mode enabled.
4. In each extension Options page and Vercel Settings, use the same Apps Script Web App URL and Spreadsheet ID. Set the user's Staff Name to keep per-user read state consistent across devices.
5. Test WhatsApp Flying Button, Track Guest Request, task creation, Ack/Handover/Done, alarm, evidence upload, notification after Completed, Reply from one client, and latest reply preview on another client.
