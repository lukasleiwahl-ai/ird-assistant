# IRD Assistant v2.7.9.9 — Staff Directory Fetch Fix

## User-reported issue
The Extension Options page displayed a manually editable `Staff list (comma-separated)` field but did not provide a way to fetch names from the Google Sheets `Staff Directory` tab. The staff name for the current computer also had no directory-backed selector.

## Root cause
The v2.7.9.8 Apps Script backend already implemented the `getStaffDirectory` action, including case-insensitive matching for `Staff Directory`, `STAFF DIRECTORY`, and `Staff_Directory`. However:
- `browser-extension/options.html` did not contain a Fetch Staff button or staff selector.
- `browser-extension/options.js` only loaded/saved manually entered values and never called the directory endpoint.
- `browser-extension/background.js` had no `FETCH_STAFF_DIRECTORY` message handler.

## Changes in v2.7.9.9
- Added a Directory sheet/tab setting (default `Staff Directory`).
- Added `Fetch Staff Names from Directory` button.
- Added a dropdown for selecting the Staff Name assigned to the current computer.
- Fetch updates the comma-separated Staff List used by Handover.
- Existing manual Staff Name and Staff List fields remain available as fallback.
- Added a background message handler which calls the existing Apps Script `getStaffDirectory` action.
- Updated extension version to 2.7.9.9 and popup label to `Extension Options / Settings`.
- Wired the existing Vercel Settings `Fetch Staff` button to the same Apps Script `getStaffDirectory` action; fetched names populate the staff dropdown and read-only list.

## Expected user flow
1. Open Extension Options / Settings from the extension popup, or use the browser's extension Options page.
2. Confirm Apps Script URL and Spreadsheet ID.
3. Keep Directory sheet/tab name as `Staff Directory` (or enter the exact tab name used in the spreadsheet).
4. Click `Fetch Staff Names from Directory`.
5. Verify the fetched count/source tab.
6. Select the staff member assigned to this computer.
7. Click `Save Settings`.

## Validation performed
- Browser extension manifest parses as JSON and remains Manifest V3.
- Options page contains the directory tab field, fetch button, staff selector, and manual fallback fields.
- Options script uses the `FETCH_STAFF_DIRECTORY` message and stores fetched names.
- Background worker handles `FETCH_STAFF_DIRECTORY` and invokes `getStaffDirectory`.
- Apps Script router already exposes `getStaffDirectory` and the case-insensitive directory reader.
- Popup has a visible shortcut to `Extension Options / Settings`.
- Vercel Settings `Fetch Staff` control is connected to the backend and renders returned names.
- Mocked UI interaction confirmed extension Options fetch → staff dropdown/list → Save Settings.
- JavaScript syntax and ZIP integrity checked.

## Not yet production-verified
This package has not been tested against the user's live Google Sheets deployment. Live fetch success requires:
- Correct Apps Script Web App URL and Spreadsheet ID in Extension Options.
- The deployed Apps Script version exposing `getStaffDirectory`.
- A Staff Directory tab whose staff names are in column A (header such as `Name` is supported).
